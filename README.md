# Atlas

**Atlas** is a personal memory and life-organisation application designed to help users collect, connect, and explore the important moments of their lives.

Rather than treating memories as isolated entries, Atlas is built around the idea that a person's life is made up of **people, places, events, and experiences that are connected to one another**.

The goal is to create a personal archive that feels more like exploring a small, private encyclopedia of your own life.

---

## ✦ Project Overview

Atlas allows users to organise their life into different **chapters**, create **memories**, and connect those memories to relevant people, places, and other entities.

The application is designed with a strong focus on:

-  **Memory** — preserving meaningful experiences and moments
-  **Connections** — linking people, places, events, and memories together
-  **Organisation** — structuring a life through chapters and timelines
-  **User experience** — creating a clean and calm interface
-  **Exploration** — making it easy to discover connections between different parts of a person's life

---

## ✦ Main Features

Atlas is currently being developed with the following features:

- **Chapters** — divide life into meaningful periods
- **Memories** — record individual experiences and moments
- **Entities** — represent people, places, objects, and other important things
- **Connections** — connect memories and entities together
- **Search** — find memories and information within Atlas
- **Timeline** — explore events chronologically
- **Themes** — customise the visual appearance of the application
- **Responsive interface** — designed for different screen sizes
- **Language support** — planned support for multiple interface languages

## ✦ Design Philosophy

Atlas aims for a visual style that is **clean, calm, modern, and personal**.

The interface takes inspiration from editorial layouts, Japanese-inspired minimalism, and modern data visualisation. The design is intended to make large amounts of personal information feel organised without making the application feel clinical or overwhelming.

The goal is not simply to store information, but to make **exploring your own life feel meaningful**.
